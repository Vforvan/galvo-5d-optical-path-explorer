## 这个页面能看到什么

| 内容 | 说明 |
|---|---|
| 三维光路 | 四个旋转振镜 A1–A4 + 一个移动透镜调焦轴 Z5 的完整追迹 |
| 结构与剖视 | 整机、光路、调焦模块、物镜与工件多个视角 |
| 口径与遮挡 | 每级镜面/透镜的通光口径检查，被挡住的路径以红色标出 |
| 焦点读数 | 工件坐标系下的 X/Y/Z 与 AOI、RotZ |
| 页内逆解 | 输入目标位姿，页内数值求解控制指令 |
| 误差对比 | 未补偿与补偿后的焦点误差 |

所有数值都是**仿真计算**，不是实机测量。

## 模型边界

- 4+1 是本项目选定的**替代研究架构**（四个旋转振镜 + 一个独立直线调焦轴），
  **不宣称复原**任何厂商设备的内部五轴机构。
- 名义几何为一阶设计值；镜面位置、轴向与支座为工程假设，不是选型结果。
- 当前模型版本为 compact-relay-4p1-v5；A2 轴线仰角 50°，后级镜组、工件原点及 A2 支承和连接轴几何已与本地 Python 模型同步。
- 不包含热漂移、伺服滞后、寿命与 650 Hz 动态能力的验证。
