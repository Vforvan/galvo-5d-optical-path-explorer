缩小焦斑会提高相同脉冲能量下的峰值能量密度。热影响还取决于脉宽、重复频率、扫描速度、脉冲重叠和材料，当前模型不预测热影响区。

默认使用保留 Fig.7 调焦模块的后级无实束腰研究版；可切换原恒焦斑条件版、偏心光程五振镜与 4+1 方案。曲面与后级镜组参数为自选，Fig.7 没有公开 precSYS 的完整内部处方。 镜中心、旋转轴、镜组焦距与结构件尺寸均为可替换假设，落地仍需实机测量、镜组设计、公差分析与闭环辨识。
