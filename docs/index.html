② 五轴指令

Z5 是移动正透镜的机械位移（±5 mm）；A1–A4 为振镜机械转角（±7°），与工件 AOI 含义不同。

③ 工作域

验收范围：XY 半径 ≤ 2.5 mm、Z ±1 mm、合成 AOI ≤ 7°。 指令在范围内也不一定可达：采样光束可能超出口径、打不到镜面，或被受检实体挡住。

光路：入射平行光 → L1 移动正透镜（+40 mm）→ L2 固定负透镜（−30 mm，名义间距 10 mm，缩束 0.75×） → M1–M4 小口径振镜 → R1（+15 mm）/ R2（+60 mm）四倍中继 → +75 mm 固定物镜 → 工件。 M4 绕 X 轴旋转、直接向下出光，因此没有固定折转镜。

追迹用向量反射与近轴薄透镜，焦点取「瞳边缘光线在平行于工件平面内横向弥散最小」的位置。 口径检查与遮挡校核用 1 条主光线加 64 条理想高斯 99% 包围能量轮廓采样线。 这不是实机的拆机复刻，也不是衍射或像差计算结果：没有真实曲率、厚度、材料、镀膜与波前传播， 受检实体也不含连续束体、压圈、热件、线束与实体间碰撞。

逆解、标定与 5D 补偿矩阵在同一个仓库的 Python 平台里（`src/five_axis_galvo/`），不在本页。本页只做正向追迹。
